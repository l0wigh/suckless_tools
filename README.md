Suckless does not only mean from Suckless team but also thing that just works out of the box for me.

- Configured DWM
- Configured st (based on luke smith one)
- Configured dmenu
- Picom configuration
- Polybar configuration
- Many Many Many scripts that I use daily
- xinitrc (mainly for [Fluorite](https://github.com/L0Wigh/Fluorite/))
- Xresources (mainly for [Fluorite](https://github.com/L0Wigh/Fluorite/))

Take what you want from there, it's free

# Scripts

- add_to_tabbed.sh: used to add the current focused window to the last tabbed window opened
- battery_checker.py: gives you a small notification to help you track your battery level
- brightness.sh: easy brightness control
- colorpicker.sh: easy color picker for X11 using xcolor and xclip
- copyclip.sh: let you copy content of files to your clipboard
- del_from_tabbed.sh: unattach a window from the current focused tabbed
- dmenu_hdmiplug.sh: let you hotplug and unplug hdmi. (plug hdmi cable, run the script, choose the resolution, xrandr will do it's work, launch the script ask for unplug, unplug the cable)
- dmenu_music.sh: control mocp
- dmenu_polybar_style.sh: let you select which polybar to use (works with my configuration)
- dmenu_power.sh: let you poweroff or reboot your computer from polybar (beware, will only work with openrc)
- dmenu_redshift.sh: toggle off and on redshift
- dmenu_xresources.sh: modify Fluorite Xresources values with ease
- dwm_bar.sh: informations for dwm_bar
- fluorite_theme.sh: hotreload Fluorite, Polybar, St, Neovim, feh with a new theme
- focus_switcher.sh: use dmenu to list all windows and select one to focus. works across multiple workspaces
- genpass: generate a random password
- gentoo-bith.sh: get the birth date of your install (please change the text to grep or it will not work)
- hdmi_hotplug.sh: at that point I don't know with one works and which one does not, but I think this one sucks
- keyboard_udev.sh: doesn't work
- multi_polybar.sh: open multiple polybar at the same time
- open_in_tabbed.sh: same as add ? I forgot, I never use it
- print_screen.sh: well, pretty easy to understand. use it with tmp arguments to copy the picture to your clipboard (requires scrot)
- record_screen.sh: ffmpeg required, might not work properly
- st_font.sh: change st terminal font on the fly
- zeroupload.sh: upload files to 0x0.st
